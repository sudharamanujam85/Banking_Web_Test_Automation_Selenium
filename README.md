
Selenium Test Automation Framework for the ParaBank demo banking application.
It follows POM (Page Object Model), uses Java + TestNG.
The design is modular, scalable, and makes it easy to maintain or update locators when the UI changes.

Why This Framework Is Strong
• Scalable and thread-safe (ThreadLocal WebDriver)
• Easy locator maintenance via POM
• Parallel test execution ready
• Cloud-ready (BrowserStack, SauceLabs)
• CI/CD ready for Jenkins, GitHub Action
